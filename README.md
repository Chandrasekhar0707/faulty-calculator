# faulty-calculator
This is a fun faulty calculator built using JavaScript.

The calculator performs basic operations:

- Addition
- Subtraction
- Multiplication
- Division

The twist is:
It uses Math.random() to intentionally produce incorrect results sometimes.

If Math.random() condition triggers:
- The calculator returns wrong answers
Otherwise:
- It returns correct answers

This project demonstrates:
- JavaScript condition handling
- Math.random() usage
- Fun logic-based implementation
